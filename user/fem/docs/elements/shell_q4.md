# 四节点空间平壳

`shell_q4` 和 `shell_q4_finite` 位于 [elements/shells/shell_q4.cpp](../../elements/shells/shell_q4.cpp)。
四个参考节点共面并沿周边排列，每节点有三个空间平移与三个旋转分量。
节点 1→2 的边确定局部第一轴，节点 1→2 与 1→4 的边叉积确定初始法向。

- **线性壳** 叠加平面应力膜刚度与 Reissner–Mindlin 板刚度。法向转角通过弱惩罚
  与平面位移的局部转动关联，再将局部刚度变换到全局自由度。
- **有限变形壳** 使用当前中面度量、随节点旋转的指向矢、MITC 剪切插值和客观法向转角稳定项。
  膜、弯曲、剪切和稳定能量共同给出内力与一致切线。
  转角用旋转向量参数化，适用范围和公式见[梁壳几何非线性](../finite_kinematics.md)。

`shell_q4` 测试倾斜面片的纯弯曲和三个方向的刚体模态。
`shell_q4_finite` 测试有限刚体转动、变形状态的切线差分、圆筒扩径和薄壳条带卷曲。
原版 FEAPpv 的有限轴对称壳用于扩径对照，卷曲用圆弧解验证。
