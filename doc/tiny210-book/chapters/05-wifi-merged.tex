\section{通信图：EP4 接收环、NAPI 与 EP4 OUT 发送}\label{wa:comm}
这一节用和 USB 键盘通信图相同的画法，把 MT7601U 的一次收发拆成 0--10 号消息：
先给出参与者（进程、中断上下文、EHCI 异步调度、Hub、芯片、AP）和它们之间的消息与锁，
然后用和 EHCI QH 队列图相同的画法，画出异步环上 EP4 IN、EP4 OUT、EP0 三个 QH 各自挂着的 qTD，并把消息号标在它作用的 qTD 上（图~\ref{fig:wifi-comm-qh}）：哪块缓冲是 \texttt{q->head}、哪块正被 HC 填、重挂挂到哪里，一眼可见；
最后逐条展开每个消息经过的函数调用链、寄存器或描述符的按位格式，以及打开
\texttt{MT7601U\_CONFIG\_TRACE} / \texttt{MT7601U\_DATA\_TRACE} 后应看到的日志。

要点有三条：
\begin{itemize}
\item 接收靠 EP4 IN QH 上一直挂着的 4 个 16\,KB qTD。HC 在异步环上自己轮询，
      一个 qTD 是一次传输，里面可能有许多个 512\,B 事务，装满或遇到短包才完成；
      完成后 IRQ 55 只做 \texttt{napi\_schedule}，解析放在 \texttt{mt7601u\_wq} 的 NAPI poll 里。
\item 一次传输里可能聚合了多个 802.11 帧（\texttt{USB\_DMA\_CFG} 打开 RX\_AGG），
      \texttt{rx\_parse} 按 DMA 头 + RXWI + MPDU + FCE 信息逐段拆开，再转成以太网帧交给 \texttt{net\_rx\_dev}。
\item 发送没有中断：\texttt{net\_xmit} 在调用者上下文里持 \texttt{dev->lock} 组 TXINFO + TXWI，
      在 EP4 OUT 上做一次同步 bulk，并忙等完成；之后从 EP0 读 \texttt{TX\_STAT\_FIFO}。
\end{itemize}
